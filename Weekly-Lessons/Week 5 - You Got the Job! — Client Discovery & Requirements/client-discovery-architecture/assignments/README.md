# Assignment — Lead a Migration Discovery

[Back to Week 3](../../README.md)

**Format:** Inventory review and client role-play. No paid AWS deployment required.

## Steps

1. Download the [50-VM simulated RVTools workbook](../requirements-gathering/Simulated_RVTools_50VM_Training_Lab.xlsx). The 150-VM and 500-VM datasets are optional extensions.
2. Summarize the inventory using the available tabs. Cite the tab/column supporting each observation.
3. Select five VMs for closer review. Record their specifications and questions about application ownership and dependencies.
4. Address **Why, RTO/RPO, 6 Rs, Timeline, and Budget** using the [requirements guide](../requirements-gathering/README.md). Mark unanswered items TBD.
5. Recommend a preliminary strategy for one application or explicitly hypothetical application group. Explain what would validate or change that choice.
6. Sketch an initial AWS architecture and propose a pilot wave with test, rollback, and acceptance criteria.

## Submit

- One-page discovery summary answering the five core questions.
- Inventory observations and a list of open questions with owners.
- Preliminary diagram and migration recommendation.
- A 60–90 second client-facing explanation of one decision and its tradeoff.

## Success criteria

All five discovery topics are covered; RTO and RPO are distinguished; the proposed R has a rationale; timeline and budget assumptions are visible; workbook evidence is separated from hypotheses; and validation/rollback criteria are included.

Carry these deliverables into the migration lesson and capstone. Do not upload credentials or actual client data.
