# Cloud Accelerator — Setup How-To Guides

Install the tools used in our AWS labs on your own computer.

| Operating system | AWS CLI | Terraform |
| --- | --- | --- |
| macOS | [Install AWS CLI](macOS/AWS-CLI.md) | [Install Terraform](macOS/Terraform.md) |
| Windows | [Install AWS CLI](Windows/AWS-CLI.md) | [Install Terraform](Windows/Terraform.md) |

**Start here:** Install AWS CLI v2 and Terraform, then run `aws --version` and `terraform version`.

**AWS access:** Use IAM Identity Center (SSO) credentials provided for your lab. Do not commit credentials, access keys, or `.aws` files to GitHub.

Official references: [AWS CLI installation](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) · [Terraform installation](https://developer.hashicorp.com/terraform/tutorials/aws-get-started/install-cli).
