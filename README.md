## Workflow

**Learn → Design → Deploy → Validate → Document → Present**

Use dedicated lab accounts, MFA, billing alerts, and least privilege. Do not commit credentials, Terraform state, or customer information. Destroy resources after labs.

> Lab instructions and examples are educational and should be reviewed before production use.
