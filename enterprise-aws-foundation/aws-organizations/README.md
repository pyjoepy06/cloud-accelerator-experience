# AWS Organizations

## Demonstration focus

- Management account versus member accounts; consolidated billing.
- Organizational units (OUs), account placement, and inheritance of SCPs.
- Why workloads should not run in the management account.
- Example: Security, Infrastructure, Sandbox, and Workloads (Dev/Test/Prod) OUs.

## Discussion prompts

1. Why use multiple AWS accounts instead of only VPC separation?
2. Where would a production account belong, and why?
3. What happens when an SCP is attached at a parent OU?

**Student deliverable:** an OU/account hierarchy with a short explanation of governance boundaries. Do not create a new AWS Organization in a personal account just for this exercise.
